# 表格规范：公式优先、数字格式、财务惯例与编辑完整性

面向用户最终交付的 Excel：报表、预算、经营数据、财务模型、统计表、清单。
核心原则：**派生值用公式、数值有格式、假设与计算分离、只改该改的**。

## 1. 公式优先（最重要的规则）

**任何"算出来的"单元格都必须写成 Excel 公式，禁止硬编码计算结果。**

- 合计行 → `"=SUM(B2:B9)"`；跨行合计 → `"=SUM(B2:B3)"`。
- 同比/环比 → `"=(B3-B2)/B2"`；比率 → `"=B3/B2"`；占比 → `"=B2/$B$10"`。
- 跨表引用 → `"=假设!B2"`（表名含空格用单引号：`"='销售数据'!D2"`）。
- 好处：用户改输入数字，Excel 自动重算，不会出现"表里数字对不上"的硬伤。
- 例外：原始录入数据（本来就是数字）不算公式；只有**派生**值要公式。

## 2. 数字格式纪律

按列给 `formats`，别裸奔：

| 场景 | formats | 说明 |
|---|---|---|
| 金额列 | `money` 或 `number` | 千分位 + 两位小数；同簿一致 |
| 数量列 | `int` | 千分位整数 |
| 比率/增长率/毛利率 | `percent` | **值存小数**（0.08=8%），不要存 8 |
| 年份列 | `year` | 防 2024 显示成 2,024 |
| 日期列 | `date` | — |

- **小数纪律**：要求两位小数就整列统一格式，禁止 12875 与 12875.00 混排。
- **负数**：金额负数显示 `(¥1,234.00)` 括号风格（对外交付标准）；全簿统一一种风格。
- **零值**：稀疏报表零值显示 `-`；数量列零值保留 0。

## 3. 假设与模型分离（财务模型）

- 假设（增长率、税率、单价、折扣）集中放一个 sheet，如"假设"：
  - 每行 = 假设名 + 数值；数值单元格配对应格式（比率 percent、金额 money）。
- 模型/计算区只写引用假设的公式：`"=B2*(1+假设!B2)"`，**不写死数字**。
- 好处：改假设一处，全表联动；审查者一眼看清哪些是可调参数。
- 简单模型也可同表分区：前几行假设块，空一行，下面模型块。

## 4. 结构规范

- **表头**：`headers` 必给，列名简短明确（"月份"不要"月"）；单位/口径写进表头或加一行说明。
- **列宽**：文本列 12~18，数字列 12~14；长文本列宽不够会截断显示。
- **冻结**：有表头就 `freeze: "A2"`，滚动时表头固定。
- **一表一事**：不同主题分 sheet（"收入""费用""利润"），不要全塞一张表。
- **空行**：数据中间不插空行（会破坏 SUM 连续区域语义），用合计行或分区。

## 5. 编辑完整性（edit_xlsx 硬规则）

1. 编辑前先 `read_xlsx` 拿当前源，**基于它写 ops**，不要凭记忆重写全表。
2. 只改任务要求的单元格/行/表；其它数据一律不动。
3. `add_row` 的列数必须与现有列数一致（多列补空串、少列会报错）。
4. `replace_text` 会跳过公式与数字——改词只影响文本。
5. 交付后 `read_xlsx` 验证：表名、行数、抽样数据、关键公式仍在。
6. 外来 xlsx 编辑前自动备份 `*_原版备份.xlsx`；那是近似导入重建的，原样式细节不在备份里。

## 6. 常见错误

| 错误 | 正确 |
|---|---|
| 合计行写死 `200000` | `"=SUM(B2:B9)"` |
| 比率存 `8`（显示 800%） | 存 `0.08` + `percent` 格式 |
| 年份列显示 `2,024` | `year` 格式（`0`） |
| 行不矩形（某行少一列） | 补空串对齐 |
| 金额格式混用 | 整列统一 `money`/`number` |
| 表头列数与数据不一致 | 对齐后再 write_xlsx |

- [ ] 负数/零值显示风格全簿一致？
