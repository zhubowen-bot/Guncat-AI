# Word 文档排版规范与场景建议

面向用户的最终 Word 交付物：报告、方案、纪要、总结、论文、说明书、工作手册。
核心原则：**结构先行、结论标题、数据可信、图片真实**。

## 1. 结构设计（动笔前先定骨架）

典型报告骨架：

```
封面（可选，正式对外文档建议加）   title + subtitle + author + date
目录（≥8 块 / 章节 ≥3 时建议加）   打开后右键"更新域"生成
H1 章节（每章一个主题）
  H2 小节（每节一个论点）
    正文段落（一段一个观点）
    表格 / 图片（证据与数据）
  H2 ……
H1 结论与下一步
```

- 章节编号自己写进标题（"一、""1.1"）或让 Word 编号，二选一，不要混。
- 内容超过 3 页没有标题，用户无法导航——**任何 >2 段的文档都要有 H2 级以上的标题**。

## 2. 标题规范

- **标题是结论句**：✗"经营情况" → ✓"上半年营收 1.2 亿，同比 +18%"。
- 一个 H1 下至少 2 个 H2；H2 下再分时至少 2 个 H3。不出现单点悬空。
- 标题层级按 1→2→3 递进，跳级（H1→H4）会让目录难看、读者困惑。

## 3. 正文与列表

- **一段一个观点**：段落首句是观点，后接 1~3 句论据（数字、事实、来源）。
- 段落长度控制：中文 3~6 行/段；整屏一段是大忌。
- 并列信息用 list（≤7 条），不用连排段落；有序 list 用于步骤/优先级。
- 强调用加粗，不用下划线、不用整段斜体；行内代码只用于文件名/API/字段名。

## 4. 表格与图片

- 表格：≤10 行、≤6 列时最易读；更复杂先考虑拆表或只列关键指标。
- 表格/图片都加 caption 题注：`表 1 …（来源：xxx）` / `图 1 …（来源：xxx）`。
- 图片质量：优先工作区里真实的截图/照片；示意图用 write_svg；**没有合适图片就不放图**，纯文字版式好过无关配图。
- 图片宽度：图表类 width 0.8~1.0，插图 0.5~0.8；过大的图（如整页截图）会糊，先裁剪。
- 数据必须来自工作区资料，禁止编造；来源写进 caption 或正文。

## 5. 场景建议

| 场景 | style | 结构要点 |
|---|---|---|
| 商务报告/方案 | default | 封面 + 目录 + 结论式标题 + 图表题注 |
| 会议纪要 | default | 无封面；H1=议题，要点用有序 list，决议加粗 |
| 论文/学术 | academic | 摘要段 → 各章 H1/H2 → 参考文献（表格列引用） |
| 内部备忘/周报 | minimal | 无封面；H1=本周主题，进展用 list，下周计划单列 |

## 6. 语言红线

- 禁用 AI 腔与黑话："赋能""闭环""抓手""综上所述""值得注意的是""不是X而是Y"。
- 用具体名词与数字："营收 1.2 亿（同比 +18%）"优于"业绩显著增长"。
- 不写空泛口号；每句都要有信息量。

## 7. 中文排版细则（中英混排、标点、数字、表格）

- **中英文字体配对**：中文正文宋体/黑体（标题黑体、正文宋体），西文与数字用 Times New Roman（正文）/ Arial（标题与强调）——中英混排时西文与数字整体用西文字体，不要用中文全角字符写英文。代码块用等宽字体（Consolas/等宽）。
- **标点**：中文句子用全角标点（，。；：""『』《》）；英文与数字之间用半角；中英文之间可加一个空格（"使用 Word 编辑"）让混排更疏朗；百分比写"18%"，区间用"~"（"3~5 天"），不用波浪号"～"。
- **数字与单位**：千位分隔（12,345 元）；金额统一（万元/亿元）并全篇一致；日期写"2026 年 3 月 21 日"或"2026-03-21"，全篇统一。
- **表格细则**：表头加粗（渲染器自动）；数字列右对齐、文本列左对齐（模型通过内容排版体现：数字前不加空格、单位放表头）；学术/正式报告可用三线表风格（表头下、表尾上两条线，中间无竖线——用"表头加粗 + 无多余装饰"表达）；单元格内容短句，不写整段。
- **公文风（GB/T 9704 简化，如用户要求"公文/红头文件"）**：标题居中（H1 即可）、正文仿宋风格（当前无仿宋预设，用正文宋体+正式表述替代，并说明）、一级标题黑体（用 H2 加粗）、成文单位与日期落款右下（用右对齐段落）。在三种样式下用"标题层级 + 右对齐段落 + 正式措辞"近似表达，不必承诺字体完全一致。
- **好/坏对照**：
  - ✗ 标题"经营情况" / ✓ 标题"上半年营收 1.2 亿，同比 +18%"
  - ✗ 一段 10 行不分段 / ✓ 一段一个观点，3~6 行
  - ✗ 表格 20 列挤成一页 / ✓ 拆表或只列关键指标，≤10 行易读
  - ✗ "综上所述，公司实现了业绩的增长" / ✓ "营收 1.2 亿，同比 +18%（来源：财务中台）"
  - ✗ 图片无题注无来源 / ✓ "图 1 月度趋势（来源：财务中台）"
