关于 Guncat Work
Guncat Work 是整合多项前沿技术打造的新一代智能体平台，旗下包含多款定位各异、能力独立的智能体：
① 轻量化掌上工作台，拥有数十种工具集与多轮任务执行能力；② 单体超级智能体，面向通用会话；③ 对话智能体，主打日常闲聊交互；⑤ 反幻觉智能体，依托 RAR 架构；⑥ 专家智能体，覆盖通用问答、资料检索、文本改写、法律服务、模型评测等垂直场景。
适配网页端、安卓端、鸿蒙手机、鸿蒙PC等多端，为用户提供便捷的智能体服务。
聊天引擎
聊天引擎对话体验和豆包类似：提出问题→给出回答。共包含4个通用对话智能体和5个专家智能体，交付速度快、效率高，不适宜执行复杂长程任务。
Agent引擎（工作模式）
Agent引擎（工作模式）的使用体验和专业编程智能体相近：布置任务→交付结果。它能调用几十种工具，进行多轮校验反思。不用你一步步指挥，就能处理文件、搜集资料、做调研、分析数据、写长文，搞定整套复杂的长线工作，但工作时长较长。
插件
插件是Guncat Work面向特定任务开发的嵌入式独立功能，目前支持表格识别插件。关于表格识别插件的使用，请参考表格识别一节的说明。
基础功能
开启和关闭深度思考（聊天引擎）
聊天引擎中的三种通用智能体可自动管理深度思考能力：轻简模式与效率模式自动关闭，专家模式则自动开启。其他智能体不支持自动开关深度思考。
开启深度思考更擅长应对高复杂度问题，处理数学计算、文稿撰写、资料调研、数据分析等任务时，以及使用垂直专家智能体时，建议启用该能力。
手动控制思考强度（工作模式）
工作模式的深度思考强制开启，提供更细化的思考档位：极高（Max）、均衡（High）、快速（Low）。在模型选择按钮处可切换不同的思考强度档位。
选择极高档位可获得极致的交付质量，但交付时间较长。选择快速档位可获得快速的交付时间，但交付质量会下降。
联网搜索：建议开启
联网搜索默认开启，建议不要手动关闭。关闭联网搜索后，模型无法获取实时网络信息，回答仅依赖过时的知识库。
联网搜索不属于本地工具，可用能力取决于对接的 API 平台，部分平台不支持该功能就会调用报错。
DeepSeek 、火山方舟等不少 API 平台在使用 OpenAI‑Completions 协议时可能报错，接入联网搜索更推荐选用 OpenAI‑Responses 或 Anthropic‑Messages 协议。
图片与附件：不同引擎不同要求
点击拍照按钮可拍照上传照片，点击文件按钮可上传本地图片和文件。工作模式还可在工作区面板上传文件。
对于聊天引擎，由于大多数模型不具备直接理解文件的能力，建议只上传图片，若上传文件模型可能报错。
对于工作模式，上传的文件会被保存到工作区沙箱，模型可调用工具对文件进行读写操作，你可以自由上传图片、PDF 或 Office 文档等任意文件。
请确保你使用的模型为多模态模型，如Deepseek-V4-Flash-Vision-Exp，而非Deepseek-V4-Flash，否则模型无法理解图片内容。
语音输入：自动入框，离线也能用
点击麦克风说话，识别结果直接进入输入框，确认后即可发送，动口不动手。
支持离线语音输入，网络不佳也能清晰识别。
朗读功能：支持后台播放
开启右上角自动朗读按钮后，回答会自动朗读，方便用户阅读和理解。
每条消息末尾还有手动朗读按钮，点击后可朗读单条消息。
支持自定义朗读速度（默认1.5倍）和音色，支持后台播放，用户可退出至后台或关闭屏幕继续收听朗读内容。
进阶功能
新功能-全局自由复制
现在，所有回答文本都能直接自由复制了，无需再手动点击复制局部按钮，想复制哪里就复制哪里，随心所欲更方便！
复制全文：纯文本和MD格式都可复制
在回答下方点击文本按钮，一键复制纯文本，自动去除AI生成的*、#等符号，免去二次调整的麻烦；
在回答下方点击MD按钮，一键复制Markdown格式，需要代码块、表格、列表等专业格式也可原样保留。
输入消息便捷回填
点击输入气泡下方编辑按钮，上一条消息自动回填至输入框，补充和修改从未如此简单。
点击复制按钮，也可复制当前输入框内容。
一键导出 Word
在回答下方点击 Word 按钮，长回答秒变排版精良的Word文档，标题、加粗、斜体、表格、公式、代码块原样保留，无需手动复制。
接收系统分享
在图库或文件管理器选中照片或文件，点击系统分享，选择 Guncat Work，即加入当前对话的待发送附件区。
若没有看到Guncat Work，请在系统分享中向右找到“全部”选项，将 Guncat Work 添加到分享列表中。
分享完成后，可新建对话或切换至其他智能体进行发送，文件暂存区不发送就不丢失。
太方便了！长程任务后台可继续工作
工作模式下，退出应用后台、熄屏等，智能体会继续在后台工作，任务不会被打断，你可以自由刷视频、看新闻，等待时间也不无聊！
快速上手
日常对话聊天：轻简模式
猪更聪明还是猫更聪明？椰子树有多高？面包放多久会变质？月亮为什么会跟着人走？
这类问题不需要复杂工具调用与深度推理，轻简模式优先给出快速高效、通俗易懂的生活化回答，满足碎片化闲聊与小科普需求。
轻任务求解：效率模式或专家模式
效率模式、专家模式相比轻简模式，回答更详细、更全面、更准确。面对同一个问题时，它会补充关键背景信息、原理说明与实用细节，逻辑完整，论据清晰。适合需要获取完整信息、做简单参考的场景，适度调用必要能力保证回答严谨充实，兼顾信息深度与回复效率。
其中，效率模式默认不开启深度思考，回答更快速。专家模式默认开启深度思考，回答质量更高。专家模式还包括了四大垂直领域专家智能体，擅长解决专业问题。
长程任务交付：工作模式
- 请结合参考资料①②，为我生成心得体会。
- 请根据根据这些电脑的价格截图，为我判断哪一款性价比最高。
- 请结合现有法律法规和标准体系，为我创作关于人工智能合规性审查的调研报告和对应的PPT。
- 请为我做一个从峨眉坐火车到青海五天四晚游的行程攻略。
这些任务需要涉及到多样的参考资料，或是多步骤拆解、分段执行的复杂目标，依靠单次简短对话完成无法实现理想的效果。工作模式下将自主梳理任务流程、分阶段完成信息整理、对比分析与内容创作，持续推进直至交付一份结构完整、结果可用的成品方案。适合报告撰写、方案规划、对比研判等具备完整交付目标的工作场景。
四大专业领域：垂直专家智能体
转换专家-论文 专用于将非论文问题转换为符合学术规范的论文格式；
检索专家-法律 通过多轮检索给出国企法律知识结构化权威分析；
检索专家-筛滤 通过RAR反幻觉推理结构，精准过滤搜索结果中的虚假信息与AI信息，提供真实可信的知识；
检索专家-研究 通过多轮推理与跨领域交叉验证，研究无法直接通过搜索得出的疑难知识。
这四大专家的能力已经包含在专家模式中，但单独选择使用时，会获得更专业的回答。
